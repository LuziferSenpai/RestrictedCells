# Restricted Cells

Restricted Cells fügt Speicherzellen mit einstellbaren Grenzen hinzu. Jede Zelle kann die Gesamtzahl der Ressourcen und die Zahl der Typen begrenzen. Beide Grenzen stellst du in der <ItemLink id="ae2:cell_workbench" /> ein.

## Tooltips

Eine Eingeschränkte Zelle zeigt Bytes und Typen wie jede Speicherzelle. Ist eine Grenze gesetzt, zeigt sie eine weitere Information:

*   **Max. Ressourcen: N (eingeschränkt)** zeigt eine Gesamtgrenze.
*   **Max. Ressourcen pro Typ: N (eingeschränkt)** zeigt eine Grenze pro Typ. Sie gilt, wenn eine <ItemLink id="ae2:equal_distribution_card" /> eingebaut ist.
*   **Eingeschränkt** zeigt, dass nur eine Typgrenze gesetzt ist.
