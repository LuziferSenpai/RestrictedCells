# Gleichverteilung

&nbsp;

<ItemImage id="ae2:equal_distribution_card" scale="4" />

&nbsp;

Ohne Karte ist **Ressourcenmenge** eine Summe für die ganze Zelle. Eine Zelle mit einer Grenze von 5.000 Ressourcen speichert insgesamt 5.000, egal wie viele Typen sie enthält.

Mit einer eingebauten <ItemLink id="ae2:equal_distribution_card" /> gilt die Menge pro Typ. Dieselbe Zelle speichert bis zu 5.000 von jedem Typ. In einer partitionierten Zelle zählen nur die partitionierten Typen.

Setzt du keine Menge, verhält sich die Karte wie in jeder anderen Zelle.

Der Bildschirm nennt das Feld dann **Ressourcen pro Typ**, und der Tooltip zeigt **Max. Ressourcen pro Typ**.
