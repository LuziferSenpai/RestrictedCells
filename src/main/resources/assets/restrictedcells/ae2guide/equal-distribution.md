# Equal Distribution

&nbsp;

<ItemImage id="ae2:equal_distribution_card" scale="4" />

&nbsp;

Without a card, **Resource amount** is a total for the whole cell. A cell limited to 5,000 resources holds 5,000 in all,
however many types it stores.

With an <ItemLink id="ae2:equal_distribution_card" /> installed, the amount applies to each type. The same cell holds up
to 5,000 of every type. In a partitioned cell, only the partitioned types count.

If you set no amount, the card works as it does in any other cell.

The restrictions screen then labels the field **Resources per type**, and the tooltip shows **Max resources per type**.
