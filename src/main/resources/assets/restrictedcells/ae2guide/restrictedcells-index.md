# Restricted Cells

Restricted Cells adds storage cells with adjustable limits. Each cell can cap the total number of resources it stores and
the number of types it holds. You set both caps in the <ItemLink id="ae2:cell_workbench" />.

## Tooltips

A Restricted Cell shows its bytes and types like any storage cell. When a limit is set, it shows one more piece of
information:

*   **Max resources: N (restricted)** shows a total limit.
*   **Max resources per type: N (restricted)** shows a limit per type, which applies with an
    <ItemLink id="ae2:equal_distribution_card" /> installed.
*   **Restricted** shows that only a type limit is set.
